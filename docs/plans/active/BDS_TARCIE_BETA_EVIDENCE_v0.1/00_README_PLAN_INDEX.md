## Purpose

Evolve Tarcie from a friction-free note and marker collector into a bounded, local-first beta-testing observation assistant that can capture notes and screenshots, package them as verifiable evidence, and submit them to Forge_Command for operator review.

Tarcie remains a capture instrument. It does not diagnose, classify with authority, repair, approve, promote, or autonomously operate the software under test.
