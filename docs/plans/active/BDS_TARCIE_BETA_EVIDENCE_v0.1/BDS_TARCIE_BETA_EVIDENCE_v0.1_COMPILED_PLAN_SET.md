# BDS-TARCIE-BETA-EVIDENCE-v0.1 — Compiled Plan Set

This compiled packet is an index-level convenience copy. The separately stored files remain the canonical review surfaces for their named roles.

## Decision

Proceed with Tarcie as a bounded, local-first beta-testing field assistant. Tarcie captures operator observations and explicit screenshots; Forge_Command validates and presents them; DataForge Local durably stores accepted evidence; SMITH governs later handoffs. Tarcie receives no diagnosis, repair, approval, promotion, or autonomous-operation authority.

## First proving slice

One Linux desktop, one deliberately selected test application, one manual beta session, text notes, timestamp markers, explicit active-window screenshots, separate hashed artifact files, a crash-safe local spool, fixture-backed localhost Forge_Command intake, a hash-bound per-item acceptance receipt, isolated DataForge Local persistence, and a read-only Beta Evidence Inbox.
