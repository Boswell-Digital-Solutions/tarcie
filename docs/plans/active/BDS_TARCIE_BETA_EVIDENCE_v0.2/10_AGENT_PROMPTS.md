# Bounded Agent Prompts

These prompts are planning assets. They do not authorize execution.

## GATE-00 source-lock prompt

> Inspect only the pinned Tarcie, Author_Forge, Forge_Command, dataforge-Local,
> contract, packaging, and PDF-component revisions named by the authorized work
> package. Produce an immutable source ledger: repository, branch, commit,
> submodules, dependency lock hashes, build/test commands, exit states, current
> IPC/routes/schemas, packaging surfaces, security capabilities, and verified
> gaps. Do not modify repositories, fetch credentials, use personal content,
> start a live beta, or infer support from build files. Fail closed on any
> unpinned source or unavailable evidence.

## Session-loader implementation prompt

> Work only under the exact separately authorized Phase 2 work package. Add a
> non-executable `.tarcie-session` loader and separate Session Hub while
> preserving the quick overlay. Reject unknown schemas, executable content,
> absolute/traversal paths, links, duplicates, hash mismatch, oversize packages,
> expired assignments, and platform mismatch. Do not add screenshot capture,
> network delivery, arbitrary PDF loading, issue creation, or autonomous
> navigation. Ship tests and evidence with the smallest coherent patch.

## PDF qualification prompt

> Using only the approved trusted template and synthetic data, verify every
> expected AcroForm field and page widget, effective value, appearance stream,
> tab/label mapping, save/reopen behavior, structured round-trip, prohibited
> active-feature absence, and visual render on the qualified Windows, macOS,
> and Linux viewer/component versions. Stop on duplicate/orphaned fields, stale
> appearances, clipped values, active content, or field loss. Do not use real
> tester data.

## RED Board prompt

> Attempt to break package parsing, identity binding, user activation,
> screenshot scope, evidence immutability, PDF trust, encrypted persistence,
> receipt idempotency, platform equivalence, and authority separation. Prioritize
> false acceptance, secret/manuscript leakage, path escape, executable package
> content, raw-pixel survival, PDF active content, duplicate IDs, silent
> fallback, and automatic GitHub mutation. Report reproducible evidence and
> smallest stop condition; do not repair or mutate the target.
